## 1 为什么有这件事

**动因**：用户要求按 Figma 模板「UI Kit - CP2077 (Community)」对本站做整体 UI 改造。代码已按 spec 全部落地（新增令牌层 / Cyber 原语层 / 全局样式，13 个文件换肤），程序侧全绿。

**现在卡在哪**：`web/` 包**没有任何单测**（`web/package.json` 里没有测试脚本），typecheck + build 只能证明「没写错」，**证明不了「看起来对不对、手感对不对」**——最终观感只能人眼验。

**这份文档给谁看**：接手的人（包括几周后的用户）要知道——改造**代码上已完成**，但**视觉验收尚未进行**；验收标准是什么、去哪对照。

**为什么不能直接往下做**：需要人眼 + 运行中的应用；且改造动了很多内联样式，**可点击区域/层级（z-index）有可能被误伤**，这类回归只有实际操作才发现。
